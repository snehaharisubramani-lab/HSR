# HSR Masala | Homemade Salem Chettiar Masala

A traditional homemade food products website showcasing authentic Salem Chettiar masalas, podis, millet mixes, thokku, oils and more.

**Website:** HSR Masala  
**Established:** 2000  
**Location:** Salem, Tamil Nadu, India

## About the Project

HSR Masala is a responsive e-commerce-style website created to bring traditional homemade Salem Chettiar food products online.

The website highlights the brand's traditional preparation methods, product collection and easy ordering through WhatsApp.

It combines Tamil cultural elements with a warm, traditional design to create an authentic shopping experience.

## Features

- **Product Catalogue:** Browse a wide range of homemade food products.
- **Product Categories:** Explore masalas, podis, instant mixes, soups, breakfast mixes, thokku, oils and desserts.
- **Product Search:** Search for products easily.
- **Product Details:** View descriptions, available quantities and prices.
- **Shopping Basket:** Add products, update quantities and calculate totals.
- **WhatsApp Ordering:** Send your selected products directly through WhatsApp.
- **Responsive Design:** Designed for desktop and mobile screens.
- **Tamil and English:** Bilingual content representing the brand's heritage.
- **Traditional Design:** Inspired by Tamil culture, kolam patterns and traditional colours.

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation is required.

## WhatsApp Integration

Customers can add products to their basket and send their order directly through WhatsApp.

The WhatsApp contact number and delivery settings can be configured in the JavaScript section of `index.html`.

## Deployment

This website can be hosted for free using **GitHub Pages**.

1. Upload the project files to a public GitHub repository.
2. Open Repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch and `/ (root)` folder.
6. Save the settings.

GitHub Pages will generate a public website link.
